# Descargador de Música

Programa independiente para Windows, **accesible con NVDA**, para buscar, escuchar y descargar música.

## Descargar
- Descarga directa del programa (exe):
  https://github.com/elgamer780/descargador-de-musica/releases/latest/download/Descargador-de-Musica.exe
- El .exe lleva incorporados yt-dlp y ffmpeg; no necesita instalación.

## Características
- Busca canciones en YouTube (por nombre o con URL).
- Acepta enlaces de canción, playlist, Facebook y contenido para mayores de 18.
- Reproduce la canción completa dentro del programa, sin cortes, con control de volumen.
- Descarga en audio (M4A, OPUS, MP3, WAV, OGG, WEBM) o vídeo (MP4).
- Spotify: canciones individuales (a través de YouTube) y álbumes o playlists completas (con spotDL y tus credenciales gratuitas).
- Le anuncia el progreso al lector de pantalla.
- Menú F1 con Ayuda y Novedades.

## Actualizaciones
- Al abrir, el programa comprueba si hay una versión nueva y se actualiza solo desde los lanzamientos de aquí.
- Los lanzamientos (Releases) contienen el .exe con la versión de la etiqueta.
